Lesson 1 — a first glimpse of HTML

What you'll learn

  • What HTML tags are and how the browser reads them.
  • Tags and attributes.
  • How a form works in plain HTML.
  • How an HTML example looks before adding CSS.

Glimpse

The example below has no stylesheet. The course navigation stays styled, while the example shows how a browser displays plain HTML tags.

A tiny guestbook form (live example)

Try submitting the form. Because method="get", your name and message appear in the page address as ?name=...&message=... — your first look at how a browser sends data to a server.

Code to add

The embedded example uses plain HTML. Here is its full source, simplified, so you can rebuild it yourself in a new file called my-first-page.html: 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My first page</title>
</head>
<body>
  <h1>Hello, web!</h1>

  <p>This page is written in plain HTML.</p>

  <form action="#" method="get">
    <p>
      <label for="name">Your name</label>
      <input id="name" name="name" type="text">
    </p>
    <p>
      <label for="message">Your message</label>
      <input id="message" name="message" type="text">
    </p>
    <p><button type="submit">Send</button></p>
  </form>
</body>
</html>

How to read this

  • Tags are words in angle brackets, like <p>. They describe what something is: a paragraph, a heading, a form. Most come in pairs — an opening tag and a closing tag with a slash, like </p>.
  • Attributes give a tag extra settings inside the opening tag. type="text" tells the input to show a one line text box. Attributes are always written name="value".
  • <head> holds page settings the visitor does not see (the title, the character set).
  • <body> holds everything the visitor CAN see.

Check it works

  1. Create a new file called my-first-page.html.
  2. Copy the code above into it and save.
  3. Double-click the file — it opens in your browser.
  4. You see a big "Hello, web!" heading and a form with two boxes.
  5. Type a name and message, then press "Send".
  6. Look at the address bar: it now ends with ?name=Ada&message=Hello. The GET method put your form data into the URL — that is what a server would receive.
