Lesson 3 — adding JavaScript

What you'll learn

  • What JavaScript is for and where it runs.
  • Events: how the page reacts to clicks and typing.
  • The DOM: how JavaScript sees and changes the page.
  • localStorage: a tiny database inside your browser.

Glimpse

This page includes assets/js/main.js. Two things on this page are already driven by it:

  1. Press Ctrl+C-style "Copy" buttons appear above every code block on this page — that is JavaScript added them at runtime.
  2. The menu button in the header only appears on small screens, and opening/closing it is handled by JavaScript (with aria-expanded updated for screen readers).

Code to add

1. Load the script at the end of body

<script src="../assets/js/main.js"></script>

2. Reacting to an event

// Find an element the same way you select it in CSS.
const button = document.querySelector('.button');

// Run this function every time the button is clicked.
button.addEventListener('click', function () {
  console.log('The button was clicked!');
});

3. Reading and changing the DOM

The DOM (Document Object Model) is the browser's map of the page. JavaScript can read it, change it, and create new nodes in it: 

// Read text.
const heading = document.querySelector('h1');
console.log(heading.textContent);

// Change it.
heading.textContent = 'JavaScript changed this!';

// Create something brand new and add it to the page.
const p = document.createElement('p');
p.textContent = 'I was created by JavaScript.';
document.body.appendChild(p);

4. Using localStorage

// Save a value under a key.
localStorage.setItem('guestbook-lesson-progress', '{"03": true}');

// Read it back (localStorage only stores TEXT, so use JSON).
const saved = JSON.parse(
  localStorage.getItem('guestbook-lesson-progress') || '{}'
);
console.log(saved);

// Remove it.
// localStorage.removeItem('guestbook-lesson-progress');

localStorage is not private and not secure: anything on the page can read it, and it never leaves the browser. It is fine for remembering "you finished lesson 3" and similar small things, but never store passwords or other secret data in it.

Check it works

  1. Add the <script src="../assets/js/main.js"></script> line before </body> in your page.
  2. Reload. A Copy button now floats on every code block.
  3. Click Copy, then paste somewhere (empty text file): the code is the same as on screen.
  4. Tick "Mark as done" and reload the page: the checkbox stays ticked — it was saved to localStorage.
  5. Tick it on two or three lessons, then open the index page: the progress bar reflects what you ticked.
  6. Open dev tools (F12) → Application → Local Storage and find the key guestbook-lesson-progress. There it is.
