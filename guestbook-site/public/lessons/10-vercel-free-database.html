Lesson 10 (optional) — a free hosted database

What you'll learn

  • Why a hosted database fixes Vercel's "ephemeral filesystem" problem.
  • How to add a free Neon Postgres database through the Vercel Marketplace on the Hobby plan.
  • What changes in the PHP code (from sqlite: to pgsql:).
  • Why you must always check the provider's current free-tier limits.

Glimpse

The change is small: your connection string switches from a local file to a URL stored in an environment variable: 

// Before (SQLite file on disk):
$db = new PDO('sqlite:' . $path);

// After (hosted Postgres, URL from an environment variable):
$url = getenv('POSTGRES_URL');
$db  = new PDO($url);

Same PDO, same prepared statements, same PHP. Only the driver changes.

Steps and code

1. Create the database in the Vercel Marketplace

  1. Open your project on vercel.com.
  2. Open the Storage tab → Create Database.
  3. Choose Neon (a hosted Postgres provider available through the Vercel Marketplace, with a free tier usable on the Hobby plan).
  4. Accept the defaults and create it. Vercel then adds POSTGRES_URL (and similar variables) to your project's environment variables automatically.

2. What changes in the code (conceptual example)

<?php
// src/config.php — the hosted-database variant (sketch).

// The connection string comes from the environment. It looks like:
// postgres://user:password@host/dbname
// It is a SECRET: it lives on the server, never in your code or repo.
$url = getenv('POSTGRES_URL');

$db = new PDO($url, null, null, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
]);

// Postgres uses SERIAL instead of SQLite's AUTOINCREMENT,
// and DOUBLE PRECISION quotes differ. Table creation differs slightly:
$db->exec(
    'CREATE TABLE IF NOT EXISTS messages (
        id         SERIAL PRIMARY KEY,
        name       TEXT NOT NULL,
        message    TEXT NOT NULL,
        created_at TIMESTAMPTZ NOT NULL DEFAULT now()
    )'
);
?>

Everything else you learned stays true: prepared statements, escaped output, the same queries (minor SQL dialect differences aside). SQLITE AUTOINCREMENT becomes SERIAL; datetime('now') becomes now().

3. Keep the secret safe

The Postgres URL contains a password. It must only live in Vercel's environment variables (Project → Settings → Environment Variables) — never inside a file you commit. Your .gitignore habit from lesson 7 applies to any local .env file too.

Free-tier reality check

Free tiers change often. Before you depend on one, read the provider's current pricing page and check:

  • monthly storage and compute limits;
  • whether the database "sleeps" when idle and takes seconds to wake (Neon's free tier does);
  • whether a credit card is required;
  • what happens if you exceed the free allowance.

Vercel's Hobby plan is for personal, non-commercial use. Always verify on vercel.com/pricing and neon.tech/pricing before you build on it.

Check it works

  1. The Vercel project's Storage tab shows your Neon database as connected.
  2. Settings → Environment Variables lists POSTGRES_URL — and its value is masked, not shown.
  3. Your PHP code reads the variable with getenv() and connects without errors (try it locally with php -S and a copy of the URL in your shell environment).
  4. Posting a message persists: restart the server, the message is still there (it now lives in Postgres, not a file).
