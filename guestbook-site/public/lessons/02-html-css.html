Lesson 2 — HTML + CSS: making it look right

What you'll learn

  • The difference between HTML (structure) and CSS (appearance).
  • How to link a stylesheet file to a page.
  • Selectors: how CSS knows which element to style.
  • The box model: every element is a box with padding, border, margin.
  • Flexbox: an easy way to line things up in a row.

Glimpse

This page uses the exact same HTML ideas as lesson 1, but now it links assets/css/style.css. See how the headings, form, buttons and layout changed — the structure did not.

Code to add

1. Link the stylesheet from your page

<link rel="stylesheet" href="../assets/css/style.css">

2. A tiny stylesheet to start with

/* style.css — plain CSS, no frameworks */

/* A selector is everything before the { }. It says WHICH
   elements the rules below apply to. Here: every <body>. */
body {
  font-family: Arial, sans-serif; /* which font to draw with   */
  margin: 0;                      /* remove the default gap    */
  padding: 1rem;                  /* space INSIDE the body box  */
}

/* One class selector: matches every element with class="card". */
.card {
  background: #ffffff;
  border: 1px solid #cccccc;   /* the box model: border        */
  padding: 1rem;               /* space inside the border      */
  margin: 1rem 0;              /* space outside the border     */
  border-radius: 8px;          /* rounded corners              */
}

/* Group two selectors with a comma: both get these styles. */
h1, h2 {
  color: #1a5fb4;
}

The box model

The browser draws every element as a rectangular box with four layers:

  1. content — your text or image;
  2. padding — clear space inside the border;
  3. border — the line drawn around the padding;
  4. margin — clear space outside the border that pushes neighbours away.
/* Visualise it: give any element a temporary red border. */
.card {
  border: 2px solid red;
}

Flexbox

Flexbox is a layout mode. Turn a container into a flex container and its children line up in a row (or column) and share the space: 

/* Line up buttons in a row with a gap between them. */
.row {
  display: flex;
  gap: 0.5rem;
  align-items: center;   /* centre them vertically */
}

Check it works

  1. Take your my-first-page.html from lesson 1.
  2. Add the <link rel="stylesheet"> line to it.
  3. Create assets/css/style.css next to it.
  4. Copy the tiny stylesheet into that file and save both.
  5. Reload the page. The text changes font and cards get a border.
  6. Open the browser dev tools (F12) and click a heading. The Styles panel shows which rules apply — and any rules that were crossed out because another rule overrode them.
  7. Shrink the window. Nothing breaks: CSS you wrote applies at every width (this site is built mobile-first with relative units).
