Lesson 12 — editing comfortably in VS Code

What you'll learn

  • How to open the project folder the right way.
  • Which extensions to install (recommended in .vscode/extensions.json).
  • When to use Live Server (static pages only).
  • How to run PHP locally with php -S localhost:8000 -t public.

Glimpse

Two local servers, two jobs — mixing them up is the classic beginner mistake:

Server Command Serves Runs PHP?
Live Server (VS Code extension) click "Go Live" HTML/CSS/JS lessons No — PHP files come out as raw text
PHP built-in server php -S localhost:8000 -t public everything Yes

Steps

  1. Open the folder, not a file. VS Code menu File → Open Folder… → choose guestbook-site. Opening the FOLDER (not a single file) is what makes the editor understand your project.
  2. Install the recommended extensions. VS Code pops up a notification with the recommendations from .vscode/extensions.json; install all three:
    • Intelephense — understands PHP: autocomplete, jump-to-definition, and error highlighting.
    • Live Server — one-click local server for static pages, with auto-reload on save.
    • Live Server (ms-vscode.live-server) — the newer official variant; either of the two works.
  3. Static pages: click "Go Live" in the bottom-right status bar. Your HTML lessons open with automatic reload whenever you save a file.
  4. PHP pages: use the terminal instead. In VS Code: Terminal → New Terminal, then: 
    php -S localhost:8000 -t public
    -S localhost:8000 starts the server on port 8000; -t public makes public/ the web root. Then open http://localhost:8000/lessons/06-final-htmx.php.

Run the PHP server from the PROJECT ROOT (the folder that contains public/, src/ and data/). The page code points at ../src/config.php relative to the FILES — this always resolves while PHP is started with -t public from the root. If you start it inside public/, the database and config land in the wrong place or the include fails.

On the first run, the SQLite file is created automatically in data/. If you get a permissions error, check that the folder exists and is writable (data/.gitkeep keeps it in Git even when empty).

Check it works

  1. Open the project folder in VS Code; the Explorer shows public/, src/, data/.
  2. The three recommended extensions appear under Extensions → Installed.
  3. "Go Live" serves 01-glimpse.html and reloads on save.
  4. php -S localhost:8000 -t public (from the root) serves the lessons AND the app at http://localhost:8000/app/index.php.
  5. After first app load, data/guestbook.sqlite exists on disk.
