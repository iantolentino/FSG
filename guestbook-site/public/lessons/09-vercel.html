Lesson 9 — free hosting with Vercel

What you'll learn

  • How to deploy the static lesson site on Vercel's free Hobby plan.
  • What Vercel is good at (static files, instant redeploys).
  • Why PHP and SQLite do not persist there.

Glimpse

When you finish, your lessons live on a URL like guestbook-site-XXXX.vercel.app — and every future git push to main redeploys it automatically. That is the magic of Vercel: hosting tied to your repository.

Steps

  1. Go to vercel.com and sign up with your GitHub account (the free Hobby plan is what you want).
  2. Click Add New… → Project.
  3. Find guestbook-site in the list of your GitHub repos and click Import.
  4. In the import screen leave everything default: Framework Preset Other, no build command, output directory public. Then click Deploy.
  5. Wait about a minute. Vercel shows a confetti screen with your URL — open it.
  6. From now on, every git push to main redeploys the site automatically.

The fine print for this project

Vercel serves this project as static files. The HTML/CSS/JS lessons work. But:

  • PHP is not executed — Vercel does not run a PHP interpreter for a plain static deployment like ours.
  • The filesystem is ephemeral. Even where code runs (their serverless functions), files written during a request are wiped when it ends: storage resets between requests. A SQLite file saved today can be gone in the next request, so a file-based database cannot live there.

Lesson 10 shows the Vercel-hosted route to a real database; lesson 11 is the classic cPanel path where our current code runs unchanged.

Check it works

  1. Your project dashboard on vercel.com shows "Ready" with a domain link.
  2. The lessons open at that domain and styling is intact (CSS loaded).
  3. Lesson checkboxes still remember your ticks (localStorage works client-side anywhere).
  4. Open /public/app/index.php there: no guestbook — the PHP is served as plain text or 404s. Expected!
  5. Edit a lesson file locally, commit, push — the live site updates within a minute or two.
